## Description

The Chat feature of Agentic OS is your personal AI tutor, available 24 / 7. It lets you hold a natural conversation with an AI agent who provides instant, tailored feedback on coursework, assignments, and exam prep. Ask questions, request step‑by‑step explanations, get study tips, or have the AI quiz you—all in one friendly chat interface.

## Features

#### 24 / 7 Personalized Tutoring

Ask questions any time—day or night—and receive answers aligned with your course and skill level.

#### Proactive Guidance (Guided Prompts)

After every response, the agent suggests follow‑up questions that nudge you toward deeper understanding and topics you may not have considered.

#### Adaptive Learning Paths

The agent continually gauges your knowledge and adjusts the depth and complexity of explanations so that every answer meets you where you are.

## How to Use (step by step)

#### Log In to Agentic OS

Sign in with your credentials. You’ll land on the main workspace dashboard.

#### Open Explore

Click Explore in the sidebar to see all available AI agents.

- One course → one agent.  
- Multiple courses → multiple agents.  
- *(Optional)* Use the category filter to narrow the list.

#### Select a Agent

Click an agent card—this guide uses the baseline Agentic OS as an example. The chat window opens.

#### Start with Guided Prompts (Optional)

At the top of the chat you’ll see suggested prompts. If you’re new, you’ll get starter prompts; returning users see prompts based on past conversations. Click one to begin.

#### Ask Your Own Question

Type directly in the message box, e.g.,  
> “What are the best study techniques?”

You can also:

- Generate self‑assessment questions.  
- Request step‑by‑step walkthroughs (e.g., a biology lab).

#### Read the Answer & Follow Up

The agent replies with a tailored explanation. After each answer, new guided prompts appear so you can dive deeper or clarify anything confusing.

#### Continue the Conversation

Keep clicking suggested prompts or type new questions. The agent adapts in real time, remembering context and adjusting answers to your evolving understanding.

#### Return Anytime

Leave and come back whenever you like—the conversation history remains, so the agent can pick up right where you left off.

## Pedagogical Use Cases

#### Study‑Strategy Coaching

> “What are the best study techniques?”  
→ Receive personalized tips on time management, memory aids, and exam prep.

#### Self‑Assessment Quizzes

> “Generate five practice questions on Chapter 3.”  
→ the agent creates custom questions; follow up with  
> “Show me the answers.”  
for instant feedback.

#### Step‑by‑Step Walkthroughs

> “Can you guide me through this biology lab experiment?”  
→ The AI breaks the procedure into clear, manageable steps.

#### Concept Deep‑Dives

After learning about a topic, click a suggested prompt like:  
> “Would you like to explore the causes of this event?”  
to uncover underlying principles and related ideas.

#### Continuous, Adaptive Learning

Early in a semester, the agent explains basics in simple terms; later, it offers advanced insights—ensuring support from introductory material to nuanced discussions.
