## Overview

Multiple ways to discover and switch between agents on the platform.

---

## From the My Agents Tab

1. Click the **My Agents** tab in the side panel.
2. Browse through pages of available agents.
3. Use the **search bar** to find a specific agent by name (e.g., "Italian").
4. Click on an agent to start chatting.

---

## From the Explore Agents Page

1. Start a **new chat** and click **Explore Agents**.
2. Or click the **agents tab** (globe icon) in the side panel.
3. Use the available filters:
   - **Community agents**: agents shared across the platform
   - **Platform agents**: agents specific to your tenant
   - **My agents**: agents you have created
4. Filter by **type**: Standard, Direct LLM, or Tool LLM Provider.
5. Filter by **category** to narrow results further.

---

## Switching Agents

- Click on any agent from the search results or explore page to switch immediately.
- You can also click **Browse All** from the new chat screen to see the full list.

---

## Key Takeaways

- **My Agents** tab provides quick access to agents you have interacted with
- **Explore Agents** offers search, filtering by source (community, platform, personal), type, and category
- Switching agents is instant — click any agent to start a new conversation
