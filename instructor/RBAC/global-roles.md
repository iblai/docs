# Global Roles

The following roles are available for tenants admins to set for a user under the `Management -> Users` tab.

- Analytics Viewer: Grants access to the AI Analytics dashboard on skills.iblai.app. User can see analytics for teams they have analytics access to. This does not grant access to view analytics for specific mentors, but aggregate analytics for teams of users.
- Billing Manager: Can view and manage platform credits (reloading credits, etc)
- Can Sell Items: Can configure items that can be sold
- Create Teams: Can create teams of individuals (Management -> Teams).
- Enrollment Manager: Can invite others to the platform
- List Teams: Can list teams current user has access to (typically used in conjunction with other permissions that require selecting teams, like when viewing aggregate analytics for teams)
- List Users: Can list users on the platform (typically used in conjunction with other permissions that require selecting users, like when selecting users to create teams)
- Mentor Chat: Can chat with any mentor in the tenant
- Mentor Editor: Can chat with any mentor view/edit all settings and information about all mentors in the tenant
- Mentor Viewer: Can chat with any mentor and view all settings and information about all mentors in the tenant
- Notification Manager: Can access alerts management and sending notifications to users/teams they have access to
