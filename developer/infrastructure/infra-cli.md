# Infrastructure CLI

Interactive CLI for provisioning and configuring the [ibl.ai platform](https://github.com/iblai/iblai-infra-cli) on AWS.

---

## Overview

**iblai-infra-cli** is an interactive command-line tool that automates the provisioning and configuration of the ibl.ai platform infrastructure on Amazon Web Services. It guides you through setup with interactive prompts, handling resource creation, networking, and service deployment.

---

## Repository

- **GitHub**: [iblai/iblai-infra-cli](https://github.com/iblai/iblai-infra-cli)
- **License**: Open Source

---

## Getting Started

```bash
git clone https://github.com/iblai/iblai-infra-cli.git
cd iblai-infra-cli
```

Run the CLI and follow the interactive prompts to provision your ibl.ai infrastructure on AWS.
