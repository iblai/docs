# Claw Setup

Connect self-hosted [Claw](https://github.com/iblai/iblai-claw-setup) servers to the ibl.ai platform.

---

## Overview

**iblai-claw-setup** enables connection of self-hosted Claw servers to the ibl.ai platform. This tool handles the configuration and authentication needed to integrate your local Claw deployment with ibl.ai's cloud services.

---

## Repository

- **GitHub**: [iblai/iblai-claw-setup](https://github.com/iblai/iblai-claw-setup)
- **License**: Open Source

---

## Getting Started

```bash
git clone https://github.com/iblai/iblai-claw-setup.git
cd iblai-claw-setup
```

Follow the setup instructions in the repository README to configure your self-hosted Claw server and connect it to the ibl.ai platform.
