# Claw Agents

48 pre-built agent configurations for [OpenClaw](https://github.com/iblai/iblai-claw-agents) instances, organized by vertical.

---

## Overview

**iblai-claw-agents** provides a curated library of ready-to-deploy agent configurations designed for various industry verticals. Each agent is pre-configured with appropriate system prompts, tool selections, and behavioral parameters.

---

## Repository

- **GitHub**: [iblai/iblai-claw-agents](https://github.com/iblai/iblai-claw-agents)
- **License**: Open Source

---

## Getting Started

Clone the repository and explore the available agent configurations:

```bash
git clone https://github.com/iblai/iblai-claw-agents.git
cd iblai-claw-agents
```

Browse the verticals directory to find agents suited to your use case, then deploy them to your OpenClaw instance.
