# Claw Agents

Pre-built agent configurations for [OpenClaw](https://github.com/iblai/claws) instances, organized by vertical.

---

## Overview

**claws** provides a curated library of ready-to-deploy agent configurations designed for various industry verticals. Each agent is pre-configured with appropriate system prompts, tool selections, and behavioral parameters.

---

## Repository

- **GitHub**: [iblai/claws](https://github.com/iblai/claws)
- **License**: Open Source

---

## Getting Started

Clone the repository and explore the available agent configurations:

```bash
git clone https://github.com/iblai/claws.git
cd claws
```

Browse the verticals directory to find agents suited to your use case, then deploy them to your OpenClaw instance.
