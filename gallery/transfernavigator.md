## Description

An agent that helps users **navigate credit transfer**—interpreting transcripts, checking articulation agreements, and mapping courses to a destination university’s degree requirements. 


It can analyze **uploaded transcripts** (including international credits), handle **credit conversions** (e.g., UK → US), explain **minimum grade requirements**, and show **how credits apply** to a chosen program.

---

## Typical Flow

#### 1. Start the conversation

  **Sample prompts:**

    “I want to transfer to Empire State University. Will my credits transfer?”
    “Can you map my courses to Empire State’s requirements?”

#### 2. Upload and analyze
  - Upload a sample transcript (PDF).  
  - Agent analyzes coursework and recognizes originating institution standards (e.g., **UK credit system**).

#### 3. Get an evaluation
  - Returns an overview with:
    - Evaluation process and what to expect  
    - Credit conversion details (e.g., UK → US)  
    - Minimum grade requirements  
    - Degree applicability (how credits fit major/core/electives)

#### 4. Map equivalents
 
  **Sample prompts:**

    “Yes, map the equivalent.”  

**Agent returns:**
  - A course-to-course mapping (e.g., *Bath University → Empire State*)  
  - Equivalencies and converted credit values

#### 5. Next steps
  - Provides actionable follow-ups for completing the transfer process, such as:
    - Required documentation  
    - Confirmation steps  
    - Advising touchpoints
