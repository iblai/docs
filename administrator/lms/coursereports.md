# Course Reports

## Purpose

Download course-level learner data and performance reports from the Administrator Panel.

---

## Accessing the Administrator Panel

1. Enter the course as a Tenant Admin or as a user with Administrator access.
2. Click the **Administrator** tab.
3. Open the **Data Downloads** tab.

---

## Available Reports

### Enrollment & Profile Data

- Grading configuration
- Learner profile information (including users who can enroll but haven’t yet)
- Anonymized enrollment report

---

### Problem & Answer Reports

1. Select scope:
   - Full course
   - Section
   - Subsection
   - Unit
   - Specific problem

2. If using a problem bank, selecting it shows available questions.
3. Click **Create Problem Response Report**.
4. Once generated, click **View Report** to download the CSV.

---

### Grade Reports

- **Generate Grade Report**
  - Overall course grades.

- **Generate Problem Grade Report**
  - More detailed per-question performance data.

---

### Open Response Assessments (ORA)

- **Generate ORA Data Report**
  - Student-submitted open response data.

- **Generate ORA Summary Report**
  - Summary-level reporting.

- **Download Submission Files (ZIP)**
  - All uploaded user files for ORA activities.

---

## Downloading Reports

- Reports may take a few seconds or minutes to generate.
- Once ready, the file name appears in the list.
- Click the file name to download or re-download.

---

## Result

From the Administrator Panel’s Data Downloads tab, you can export detailed learner enrollment, grading, problem-level, and open-response data for any course.
