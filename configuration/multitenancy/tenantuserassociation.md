# Tenant-User Association

<iframe width="560" height="315" src="https://www.youtube.com/embed/fdWCEHqy5-w" title="YouTube video player" frameborder="0" allowfullscreen></iframe>

## Purpose

Create a tenant-admin user who can manage more than one tenant.

---

## Create the Admin User

- In **Data Manager**, expand **IBL AI Services** and click **New Tenant Users**.  
- Enter the new person’s **Name**, **Email/Username**, and **Password** (e.g., “Ashlin B12”).  

- Ensure this user is an **admin**:

  - **edX RO** stays **Instructor** (default)  
  - **Web RO** stays **IBL Admin** (default)

- Choose the appropriate **Platform**, select an existing **tenant**, type the password again, and click **Save**.  
- Look for the **green confirmation message** showing the user was created.

---

## Link the User to a Second Tenant

- Return to **Home → User Platform Links**.  
- Note the newly created user’s **ID** (example: 129).  
- Click **Add User Platform Link**.  
- Search for and select that user (recent entries appear first).  
- Pick a different **Platform** (example: editech).  
- Check **Is Admin** and **Is Staff**.

  - Marking **Is Staff** also grants **ATX access** for course-authoring tasks if desired.

- Click **Save**.

---

## Result

The user now appears as a **Tenant Admin** in each chosen tenant and, where selected, as **staff** with course-authoring privileges.
