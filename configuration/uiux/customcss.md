## Purpose

Apply custom CSS to brand your dedicated tenant beyond the default styling. Adjust button colors, backgrounds, toggles, and other visual elements.

---

## Access Advanced CSS Settings

1. Click your **profile icon** in the top right.
2. Click your **tenant name**.
3. In the **Organization** tab, scroll to **Advanced Tenant Settings**.
4. Locate the **Advanced CSS** field.

---

## Apply Custom CSS

1. Write or paste your CSS rules into the **Advanced CSS** field.
2. Click **Save**.
3. Exit the settings — changes apply immediately.

### Example Changes

- Button colors (e.g., changing blue buttons to your brand color)
- Learner/instructor toggle color
- Background colors
- Any element accessible via CSS selectors

---

## Other Organization Settings

From the same Organization tab, you can also configure:
- **Support link**
- **Email address**
- **Help center link**
- **Logos**

---

## Key Takeaways

- Custom CSS is entered in the **Advanced Tenant Settings** section
- Changes take effect immediately after saving
- You can override any default styling using standard CSS selectors
- This applies tenant-wide to all users in your platform
