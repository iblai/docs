## Overview

UI/UX enhancements to the screen sharing experience when using the agent inside the Canvas LTI 1.3 side panel. These updates give users more control over audio, mute state, and conversation transcripts during screen sharing sessions.

---

## Starting a Screen Share

1. Open the agent in the Canvas **side panel**.
2. Initiate screen sharing from the agent controls.
3. The agent will respond once it can see the shared screen.

---

## Audio Controls

- **Mute yourself**: prevents the agent from hearing you (useful in noisy environments or when pausing the conversation)
- **Mute the agent**: silences the agent's verbal responses while still receiving text in the screen share preview
- Both controls are accessible from the side panel during an active screen share

---

## Text Streaming During Muted Audio

When the agent's audio is muted:
- Voice communication remains available in both directions
- The agent's response streams as **text** in the screen share preview below
- This allows you to read responses without audio

---

## Ending a Screen Share

1. Click **Stop Screen Sharing** (available from two locations in the UI).
2. Upon ending, a **full transcript** of the screen sharing conversation appears in the chat.
3. The transcript preserves the complete exchange for reference.

---

## Key Features

- **Mute/unmute controls** for both user and agent audio
- **Text preview** of agent responses during muted state
- **Automatic transcript** generated when screen sharing ends
- **Status indicators** visible in the side panel throughout the session
