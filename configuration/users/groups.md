## Create a Group

- In the admin console, open **Groups**.  
- Click **Add Group**.  
- Enter a name (e.g., IBL V1).  
- Search for and select the users you want in the group.  
  - If your tenant is new, you may have only a few users; groups grow as more users are added.  
- Click **Add** to save the group.  
- You can reopen the group’s dropdown at any time to view or add members.

---

## Edit an Existing Group

- Open **Groups** and select the group’s dropdown.  
- View current members.  
- Add or remove users as needed.  
- Multi-select and advanced search options (e.g., by company name or other attributes) are coming soon.

---

## Create a User-License Pool (Data Manager)

- Switch to **Data Manager → User Licenses**.  
- Click **Add User License**.  
- Fill out:

  - **Name** (e.g., IBL Licensing Demo)  
  - **Count** – total seats, e.g., 20  
  - **Start Date / Expire Date** (optional)  
  - **Platform** – choose the platform this license pool belongs to  

- Click **Save**.  
- The new license pool now appears in the tenant admin’s **Analytics** view.

---

## Assign Licenses to a Group (Tenant Admin)

- In **Analytics**, open **Licenses**.  
- Select the license pool you just created (e.g., Licensing Demo).  
- Choose **Group assignment**.  
- Pick the group you created earlier (IBL V1).  
- Click **Assign**.  

The licenses are now distributed to all members of that group.  
To verify, open **Groups → your group → Licenses**; the assignment is listed there.

---

## Key Points to Remember

- **Groups** simplify license management—assign once, cover many users.  
- **User-license pools** control seat counts and expiration windows.  
- You can always:

  - Add more users to a group.  
  - Reassign or retire licenses by changing group membership or license pools.

- Upcoming features will make bulk user selection and advanced searching even easier.

---

With these steps, you can quickly organize users into groups and allocate licenses in MentorAI Analytics without manual per-user work.
